### ✨ Projeto em Destaque: QuiosqueBI

<a href="https://github.com/jv-dias/QuiosqueBI-Frontend">
  <img align="center" src="https://github-readme-stats.vercel.app/api/pin/?username=jv-dias&repo=QuiosqueBI&theme=vision-friendly-dark" />
</a>

O **QuiosqueBI** é uma plataforma de Business Intelligence que construí do zero. Ele permite que usuários façam upload de planilhas e, usando **linguagem natural**, recebam análises e gráficos gerados dinamicamente por uma **IA Generativa (Google Gemini)**.

O projeto demonstra um ciclo de desenvolvimento completo, desde a concepção até o **deploy automatizado (CI/CD) na nuvem do Azure**, com uma arquitetura segura e escalável.

* **Veja o Frontend no Ar:** [quiosquebi.azurestaticapps.net](https://victorious-dune-05e42d21e.1.azurestaticapps.net)
* **Repositório do Backend (.NET):** [jv-dias/QuiosqueBI-Backend](https://github.com/jv-dias/QuiosqueBI-Backend)
* **Repositório do Frontend (Vue.js):** [jv-dias/QuiosqueBI](https://github.com/jv-dias/QuiosqueBI)
